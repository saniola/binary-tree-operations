# Binary Tree Operations

Small Python scripts for traversing a binary tree to find the maximum, minimum, and sum of all node values.

## Features

- `tree_node.py` — defines `TreeNode` and builds a sample binary tree
- `task_01.py` — finds the largest value via recursive traversal
- `task_02.py` — finds the minimum value by following left child pointers
- `task_03.py` — computes the sum of all node values via recursive traversal

## Technology

- Python 3

## Running

```
python task_01.py
python task_02.py
python task_03.py
```
